# Slides

Open `index.html` in a browser. Everything is local (reveal.js 5.1.0 in `vendor/`), so it works offline.

- `→` / `Space`: next step, `←`: back
- `S`: speaker view (notes, timer, next slide)
- `F`: full screen, `Esc`: slide overview
- PDF backup: open `index.html?print-pdf` in Chrome and print to PDF
